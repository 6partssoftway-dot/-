# 洗濯機修理 同意書アプリ

`index.html` を開くだけで動作する単体アプリです。フォーム入力 → 署名 → 送信で、Notion（GAS Webhook経由）への記帳、Gmail経由でのお客様への領収書メール送信（PDF添付）、PDF領収書のダウンロードを行います。

## ファイル構成
- `index.html` … アプリ本体
- `manifest.json` … PWA設定（アプリ名・アイコン・起動時の見た目）
- `service-worker.js` … オフラインキャッシュ用の最小構成スクリプト
- `icons/` … アプリアイコン（自動生成した簡易デザイン。差し替え可）

## 1. スマホでアプリ化して使う（PWA）
このアプリをスマホのホーム画面に置いてアプリのように起動するには、**HTTPSで配信されている場所**に置く必要があります（`file://`で直接開いた場合、ホーム画面追加はできても正式なPWAインストール・オフラインキャッシュは動きません）。

おすすめの方法（無料・すぐできる）:
1. GitHub Pages / Netlify / Vercel などに `アプリ` フォルダ一式をそのままアップロード
2. 発行されたURL（`https://〜`）をスマホのブラウザで開く
3. **Android(Chrome)**: メニューから「アプリをインストール」→ ホーム画面にアイコンが追加される
4. **iPhone(Safari)**: 共有ボタン →「ホーム画面に追加」

ホスティング先の候補が決まっていない場合は、いつでも相談してください。GitHub Pagesなら数分でHTTPS配信のURLを用意できます。

## 2. アイコンについて
`icons/` 内のPNGは、青地に洗濯機ドラムを模した簡易デザインを自動生成したものです。ロゴ画像がある場合は同じファイル名・サイズ（192×192, 512×512, 180×180、maskable版512×512）で差し替えてください。

## 3. 領収書PDF・メール送信について
送信時に自動でPDF（お客様控え・領収書）を生成し、成功画面の「領収書PDFをダウンロード」から保存できます。メールアドレスが未入力の場合でも、この方法で控えをお渡しできます。

メール送信は **EmailJSではなくGAS（Google Apps Script）側のGmail送信に統一**しました（EmailJSの添付ファイル機能は有料プラン限定だったため）。`index.html`は送信時にメールアドレス・PDFのBase64・作業内容などをまとめてGAS Webhookに1回POSTし、GAS側で
1. Notionへの記帳
2. Gmail経由でのPDF添付メール送信（メールアドレスが未入力/「メールなし」チェック時はスキップ）

を両方行います。GAS側の実装は「5. GASコードの更新」を参照してください。

追加費用はかかりませんが、Gmail送信には1日あたりの送信件数上限があります（個人のGoogleアカウントで1日500通程度が目安）。通常の訪問件数であれば問題になりません。

## 4. メールアドレス入力の簡略化
お客様がローカル部分（`@`より前）だけ入力し、ドメインは主要プロバイダ（gmail.com / yahoo.co.jp / icloud.com など）をプルダウンから選ぶ方式にしました。一覧にないドメインは「その他（自由入力）」から手入力できます。

「メールアドレスをお持ちでない」にチェックすると、メール入力は不要になり、送信処理でもメール送信をスキップします（PDFダウンロードでの受け渡しのみになります）。

## 5. GASコードの更新（手取り自動計算＋PDF添付メール）
`index.html` は送信時、以下のルールで `netAmount`（手取り額）を計算し、Notion書き込み用のペイロードに含めて送信します。

```js
function calcNetAmount(payment, total) {
  if (payment === 'カード') return Math.round(total * (1 - 0.025)); // カード：2.5%手数料控除
  return total; // 現金・振込：手数料なし（売上そのまま）
}
```

QRコード決済は現在運用されていないため、支払い方法の選択肢からは削除しました。

GAS側（`script.google.com`で管理しているスクリプト。**このリポジトリ／GitHub Pagesには絶対に含めないこと** — Notion APIトークンなど機密情報を含むため）は、以下2点を追加で行うよう更新済みです。

1. `properties["手取り"]` にNotionへ書き込み（Notion側のプロパティ名が「手取り」と完全一致している前提。違う名前の場合はGASコード内のキー名を実際のプロパティ名に合わせて修正）
2. `sendReceiptEmail(data)` 関数で、送られてきた `email` 宛にGmail経由で領収書メールを送信し、`pdfBase64` があればPDFとして添付

デプロイ手順:
1. https://script.google.com で対象プロジェクトを開く
2. コードを新しい内容に置き換えて保存
3. 初回のみ、Gmail送信の権限を求める確認画面が出るので許可する
4. 「デプロイ」→「デプロイを管理」→ 既存のデプロイの鉛筆アイコン（編集）→ バージョン「新バージョン」を選択 →「デプロイ」
   - **新規デプロイを作成すると別URLになりindex.html側のGAS_URLと食い違うため、必ず「既存のデプロイを編集」すること**
5. `testNotion()` 関数を一度実行し、Notionに正しく手取り列が入るか、（emailを自分のアドレスにして）メールが届くか確認してから本番運用する
