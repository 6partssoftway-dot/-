# 洗濯機修理 同意書アプリ

`index.html` を開くだけで動作する単体アプリです。フォーム入力 → 署名 → 送信で、Notion（GAS Webhook経由）への記帳とお客様へのメール送信、PDF領収書の発行を行います。

## ファイル構成
- `index.html` … アプリ本体
- `manifest.json` … PWA設定（アプリ名・アイコン・起動時の見た目）
- `service-worker.js` … オフラインキャッシュ用の最小構成スクリプト
- `icons/` … アプリアイコン（自動生成した簡易デザイン。差し替え可）

## 1. スマホでアプリ化して使う（PWA）
このアプリをスマホのホーム画面に置いてアプリのように起動するには、**HTTPSで配信されている場所**に置く必要があります（`file://`で直接開いた場合、ホーム画面追加はできても正式なPWAインストール・オフラインキャッシュは動きません）。

おすすめの方法（無料・すぐできる）:
1. GitHub Pages / Netlify / Vercel などに `アプリ` フォルダ一式をそのままアップロード
2. 発行されたURL（`https://〜`）をスマホのブラウザで開く
3. **Android(Chrome)**: メニューから「アプリをインストール」→ ホーム画面にアイコンが追加される
4. **iPhone(Safari)**: 共有ボタン →「ホーム画面に追加」

ホスティング先の候補が決まっていない場合は、いつでも相談してください。GitHub Pagesなら数分でHTTPS配信のURLを用意できます。

## 2. アイコンについて
`icons/` 内のPNGは、青地に洗濯機ドラムを模した簡易デザインを自動生成したものです。ロゴ画像がある場合は同じファイル名・サイズ（192×192, 512×512, 180×180、maskable版512×512）で差し替えてください。

## 3. 領収書PDFについて
送信時に自動でPDF（お客様控え・領収書）を生成し、成功画面の「領収書PDFをダウンロード」から保存できます。メールアドレスが未入力の場合でも、この方法で控えをお渡しできます。

### メールにPDFを添付するには（EmailJS側の設定が必要）
現在のコードは、メール送信時にPDFのBase64データ（`pdf_base64`）とファイル名（`pdf_filename`）をEmailJSに送っています。ただし**実際にファイル添付として届くかどうかはEmailJSのテンプレート設定次第**で、この設定はEmailJSダッシュボードでの操作になるため、こちらでは代行できません（ログイン情報を扱うため）。

設定手順（EmailJSダッシュボード）:
1. https://dashboard.emailjs.com/ にログイン
2. Email Templates → 使用中のテンプレート（`template_6k7losz`）を開く
3. 「Attachments」欄で「Add attachment」→ Dynamic file (Variable) を選択
4. 変数名を `pdf_base64`、ファイル名を `{{pdf_filename}}` に設定して保存

これで次回送信からPDFがメールに添付されます。コード側の変更は不要です。
※ EmailJSのプランによって添付可能な合計サイズに上限があります（無料プランは1メールあたり数百KB程度が目安）。件数が多い作業でPDFが大きくなる場合は上限にご注意ください。

## 4. メールアドレス入力の簡略化
お客様がローカル部分（`@`より前）だけ入力し、ドメインは主要プロバイダ（gmail.com / yahoo.co.jp / icloud.com など）をプルダウンから選ぶ方式にしました。一覧にないドメインは「その他（自由入力）」から手入力できます。

「メールアドレスをお持ちでない」にチェックすると、メール入力は不要になり、送信処理でもメール送信をスキップします（PDFダウンロードでの受け渡しのみになります）。

## 5. Notion「手取り」列の自動計算について
`index.html` は送信時、以下のルールで `netAmount`（手取り額）を計算し、Notion書き込み用のペイロードに含めて送信するようになりました。

```js
function calcNetAmount(payment, total) {
  if (payment === 'カード') return Math.round(total * (1 - 0.025)); // カード：2.5%手数料控除
  return total; // 現金・振込：手数料なし（売上そのまま）
}
```

QRコード決済は現在運用されていないため、支払い方法の選択肢からは削除しました。

**重要：** 実際にNotionの「手取り」列へこの値を書き込むのは、Notion APIを呼び出しているGoogle Apps Script（GAS）側の処理です。今回はそのコードにアクセスできなかったため、HTML側の送信データに `netAmount` を含めるところまで対応しています。GASのコードが見つかったら、Notionページ作成・更新の `properties` を組み立てている箇所に、以下のようなイメージで1行追加してください（実際のプロパティ名・型はNotion DB側の設定に合わせて調整が必要です）。

```js
// GAS側の例（Notion API へのリクエストを組み立てている箇所に追記）
// data はこのアプリからPOSTされたJSON（JSON.parse(e.postData.contents) など）
properties["手取り"] = {
  number: data.netAmount
};
```

GASのコードを共有いただければ、その場で該当箇所を実装します。
